# 📁 Panduan Folder Asset Portofolio Zia

Folder ini adalah tempat untuk menyimpan semua foto, sertifikat, dan dokumen. Semua file di sini bisa langsung diakses di browser melalui path `/assets/...`.

---

## 🗂️ Struktur Folder

### 1. `foto/`
Tempat foto profil dan dokumentasi pribadi Zia:
* `profil.jpg` atau `profil.png` → Foto utama profil Zia (disarankan rasio 1:1 atau 3:4, formal/semi-formal yang cantik).
* `hero-zia.jpg` → Foto pendukung untuk section beranda.

### 2. `sertifikat/`
Tempat scan atau foto sertifikat & penghargaan:
* `lkti-ugm.jpg` → Sertifikat Juara 2 LKTI Nasional UGM.
* `mun-ui.jpg` → Sertifikat Best Delegate MUN Universitas Indonesia.
* `financial-modeling.jpg` → Sertifikat Pelatihan Bloomberg x FEB UB.
* `mawapres.jpg` → Piagam Mahasiswa Berprestasi FEB.
* `seminar-syariah.jpg` → Sertifikat Seminar Nasional.
* `digital-marketing.jpg` → Sertifikat Google Workshop.
* `business-case.jpg` → Piagam Finalis Business Case ITB.

### 3. `organisasi/`
Tempat dokumentasi kegiatan kampus:
* `bem-feb.jpg` → Foto kegiatan Departemen Pendidikan BEM.
* `hima-akuntansi.jpg` → Foto kegiatan HIMA.
* `kspm.jpg` → Foto kegiatan Galeri Investasi / Pasar Modal.
* `volunteer.jpg` → Foto kegiatan relawan mengajar.

### 4. `dokumen/`
Tempat file dokumen jika ingin bisa di-download:
* `cv-nur-azizah.pdf` → Curriculum Vitae (CV) Zia dalam format PDF.

---

> 💡 **Tips Format & Ukuran Gambar:**
> - Gunakan format `.jpg`, `.jpeg`, `.png`, atau `.webp`.
> - Ukuran file ideal: di bawah 1 MB per foto agar web terbuka super cepat.
